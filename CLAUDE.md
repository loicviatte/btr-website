# Break The Routine website — notes for Claude

- Owner: Loïc (French speaker; reply in French, keep it short, come with solutions). Podcast host: Marius Iepure. Co-founders: Marius, Alexandra Lukey, Loïc. Georgia is in the team.
- Stack: Next.js 15 (App Router), React 19, static pages. Deploy: Vercel from `main` (push = deploy).
- Source of truth for the look: `design/*.dc.html` (Claude Design canvas pages, also on the canvas "BTR Website": https://claude.ai/artifact/8b6pfW4j7HEfXn26Jx4Bdp). `npm run compile` turns them into `components/dc/*.jsx`, the routes in `app/`, and `app/dc.generated.css`. Never hand-edit generated files; edit `design/` then compile.
- Each design page = HTML template with `{{holes}}`, `<sc-for>`, `<sc-if>`, `<dc-import>` + a `class Component extends DCLogic` script (React class component; `renderVals()` feeds the template). Runtime helpers: `lib/dc.js` (`css()`, `dcUrl()` maps `X.dc.html` links to routes and `/_blob/<id>` to `public/assets/<id>.<ext>`).
- Motion layer (`btrMotion` in each page script + the `/* motion */` CSS block): scroll reveals, header shadow, button hover. Added by `tools/episode-generator/motion.py`.
- Episode pages are generated by `tools/episode-generator/build_eps.py` (data in `epdata.py`, `reels.json`, `trans.json`), then patched by `responsive.py`, `linkprefix.py`, `fixes.py`, `motion.py` (paths inside are from the original build machine; adjust `P`).
- Constraints: the Ask page (`/ask`) is never linked from the site (shared via Instagram only). Footer credit stays exactly "A Dance United & Oti Marius Dance Studio Production · © 2026 Break The Routine". PP Monument fonts are licensed: keep the repo private. Don't deploy anything without Loïc's go-ahead.
- Not wired yet: Ask form backend, embedded YouTube players (links open YouTube at the timecode), Instagram reel videos (Graph API `media_url`), automatic page creation when a new episode goes public on YouTube.
